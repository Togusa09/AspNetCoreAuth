JWT/Bearer token authentication uses a jwt access token in the `Authenticate` header prefixed with `Bearer`

Add to the OIDC setup in `program.cs` to store the access token provided from the OIDC login so we can pull it back out later in the request
```csharp
options.Events.OnTokenResponseReceived = context =>
{
    context.Properties!.StoreTokens(new[]
    {
        new AuthenticationToken
        {
            Name = "jwt_token",
            Value = context.TokenEndpointResponse.AccessToken
        },
    });

    return Task.CompletedTask;
};
```

Register HttpContext provider the startup in `program.cs` to allow access to the HttpContext:
```csharp
builder.Services.AddHttpContextAccessor();
```

Add auth controller for testing the jwt bearer token auth

```csharp
public class JwtAuthController(IHttpContextAccessor httpContextAccessor) : Controller
{
    public IActionResult Index()
    {
        return View();
    }

    [Authorize]
    [HttpGet("JwtAuth/GetUserJwt")]
    public async Task<IActionResult> GetUserJwt()
    {
        var token = await httpContextAccessor.HttpContext.GetTokenAsync("jwt_token");
        return Json(token);
    }

    [Authorize(AuthenticationSchemes = "Bearer")]
    [HttpGet("JwtAuth/TestJwt")]
    public IActionResult TestJwt()
    {
        return Json("JWT worked successfully");
    }
}
```
