# Authorization Attributes

The two main attributes you will use for auth are 
### AuthorizeAttribute
Info about authorize attribute here

#### AllowAnonymousAttribute
When an `AuthorizeAttribute` is on the controller, all methods will require authorization by default. The can be excepted from this by adding an `AllowAnonymous` attribute, or have additional requires added with another `Authorize` attribute. `AllowAnonymous` does not have the same  behavior of increasing specificity as `Authorize`. If a controller is marked as `AllowAnonymous`, then any `Authorize` attributes will be ignored. To avoid accidentally doing an optus (ie. accidentally unsecuring an entire endpoint), try to be specific  with the use of `AllowAnonymous`, and avoid using it at a controller level if possible.

## Task Two

1. Create `Task02Controller` and add the following code
```csharp
[Route("Task02")]
[ApiController]
public class Task02Controller : Controller
{
    public IActionResult Index()
    {
        return View();
    }

    [Authorize]
    [HttpGet("Authenticated")]
    public IActionResult Authenticated()
    {
        return Json("Authenticated Request");
    }

    [AllowAnonymous]
    [HttpGet("Anonymous")]
    public IActionResult NotAuthenticated()
    {
        return Json("Not Authenticated Request");
    }
}
```
