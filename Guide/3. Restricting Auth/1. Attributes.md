# Authorization Attributes

The two main attributes you will use for auth are `AuthorizeAttribute` and `AllowAnonymousAttribute`. AllowAnonymous marks a controller or method as not requiring authentication, and AuthorizeAttribute marks a marks a controller or method as requiring authentication. Additional authorisation requirements can be specified in the attribute, but if left empty it will use the default authorisation configuration.

When an `AuthorizeAttribute` is on the controller, all methods will require authorization by default. The can be excepted from this by adding an `AllowAnonymous` attribute, or have additional requires added with another `Authorize` attribute. `AllowAnonymous` does not have the same  behavior of increasing specificity as `Authorize`. If a controller is marked as `AllowAnonymous`, then any `Authorize` attributes will be ignored. To avoid accidentally doing an optus (ie. accidentally unsecuring an entire endpoint), try to be specific  with the use of `AllowAnonymous`, and avoid using it at a controller level if possible.

## Task Two

1. Create `Task02Controller.cs` and add the following code
```csharp
/// <summary>
/// Controller for task 2 - Cookie Authentication
/// </summary>
[Route("Task02")]
[ApiController]
public class Task02Controller(ILogger<Task02Controller> logger)
   : Controller
{
   [Authorize]
   [HttpGet("Authenticated")]
   public IActionResult Authenticated()
   {
	   logger.LogInformation("Accessing authenticate endpoint with user {name}", User.Identity!.Name);
	   return Json("Authenticated Request");
   }

   [AllowAnonymous]
   [HttpGet("Anonymous")]
   public IActionResult NotAuthenticated()
   {
	   logger.LogInformation("Accessing anonymous endpoint with user {name}", User.Identity!.Name);
	   return Json("Not Authenticated Request");
   }
}
```
