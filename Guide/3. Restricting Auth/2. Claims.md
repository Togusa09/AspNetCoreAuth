### Customising identity
The dotnet core claims identity defaults to using `ClaimTypes.Name` and `ClaimTypes.Roles` as the claim types to source user name and role information from. Different claims can specified for this when creating the ClaimsIdentity object. Roles will be covered in more depth in the next section.
