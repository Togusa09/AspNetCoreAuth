List of values that represent information about a user

## Viewing Claims
Testing as un-authenticated user

Create `ClaimsController` with code:
```csharp
[Route("Claims")]
[ApiController]
public class ClaimsController : Controller
{
    [AllowAnonymous]
    public IActionResult Index()
    {
	    // View should already exist in workshop assets
        return View();
    }

    [AllowAnonymous]
    [HttpGet("UserInfo")]
    public IActionResult TestAnonymous()
    {
        return OkResponse("Get User Info");
    }

    private IActionResult OkResponse(string action)
    {
        return Ok(new
        {
            Name = User.Identity?.Name ?? "Anonymous",
            Action = action,
            AuthenticationType = User.Identity?.AuthenticationType ?? "None",
            IsAuthenticated = User.Identity?.IsAuthenticated ?? false,
            Claims = User.Claims.Select(x => new {x.Type, x.Value})
        });
    }
}
```

## Adding claims


Common claims - https://learn.microsoft.com/en-us/windows-server/identity/ad-fs/technical-reference/the-role-of-claims#what-are-claim-types

In `LoginController.Login`, use the following code to add additional claims to the user

```csharp
	   identity.AddClaims(
	   [
	       new Claim("craft", "Mercury"),
	       new Claim("role", "Pilot")
	   ]);
	```

Claims are cached in the auth cookie, so will need to log out and back in to get updated claims.

1. Logout
2. Log in as "Wally" again
3. Return to claims page and get claims. New claims will show

![[WallyUserInfoExtraClaims.png]]

Note that "role" is mapped due to being a common claim type, but "craft" is not

## Claims Transformation (Optional)
Implementing the `IClaimsTransformation` interface also provides a way to transform a users claims (https://learn.microsoft.com/en-us/aspnet/core/security/authentication/claims?view=aspnetcore-9.0#extend-or-add-custom-claims-using-iclaimstransformation) however it has some limitations which lead to updating claims in scheme events being preferable. Only one implementation can be registered, and it is run against all auth schemes.
