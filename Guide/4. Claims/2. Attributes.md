As `Authorize` attribute is on the controller, all methods will require authorization by default. The can be excepted from this by adding an `AllowAnonymous` attribute, or have additional requires added with another `Authorize` attribute.

Note: `AllowAnonymous` does not have the same  behavior of increasing specificity as `Authorize`. If a controller is marked as `AllowAnonymous`, then any `Authorize` attributes will be ignored. To avoid accidentally doing an optus (ie. accidentally unsecuring an entire endpoint), try to be specific  with the use of `AllowAnonymous`, and avoid using it at a controller level if possible.
